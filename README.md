# obwaya

Забирает курс с публичной ссылки Mail.ru Облака, распаковывает многотомный
запароленный архив и складывает готовые уроки в Google Drive.

Смысл в том, что **на твоём компьютере не оседает ничего**. Качает и
распаковывает бесплатная виртуалка Google Colab, результат сразу уезжает в
Drive, а виртуалка вместе с архивами растворяется. Диск нужен только Drive,
и там его обычно много.

## Как запустить

1. Открой [`mailru_to_drive.ipynb`](mailru_to_drive.ipynb) в
   [Google Colab](https://colab.research.google.com/) — «Файл → Загрузить
   блокнот».
2. В первой ячейке вставь ссылку на папку Mail.ru и пароль от архива.
3. Выполняй ячейки сверху вниз, дожидаясь каждой.

Вкладку не закрывай: Colab отключает простаивающие сессии примерно через
90 минут. Если загрузка оборвалась — просто запусти ячейку загрузки
заново, она продолжит с места обрыва.

Ноутбук работает и вне Colab — в обычном Jupyter на своей машине или на
сервере. Тогда Google Drive не подключается, и результат складывается в
`~/obwaya-out`.

## Что внутри

| | |
|---|---|
| `mailru_to_drive.ipynb` | Собственно ноутбук. Сгенерирован, руками не правится. |
| `tools/build_notebook.py` | Исходник ноутбука. Правь его и пересобирай. |
| `tools/selftest.py` | Тесты. |

Ноутбук держим сгенерированным: править питон в обычном `.py` приятнее,
чем экранированный JSON внутри `.ipynb`, да и диффы читаются.

```bash
python3 tools/build_notebook.py   # пересобрать после правок
python3 tools/selftest.py         # прогнать тесты
```

## Что проверено тестами

`selftest.py` вытаскивает ячейку с функциями прямо из готового `.ipynb` и
выполняет её — то есть проверяется ровно тот код, который увидит
пользователь, а не отдельная копия.

- **Докачка после обрыва.** Поднимается локальный сервер, который понимает
  `Range`, но первые две попытки рвёт соединение на середине. Проверяется,
  что загрузчик продолжает с места обрыва (а не с нуля), что файл в итоге
  совпадает байт в байт и что уже скачанный файл не качается повторно.
- **Настоящая распаковка.** Собирается многотомный запароленный архив из
  несжимаемых данных, с вложенными папками и кириллицей в именах.
  Проверяется, что все файлы распаковались нужного размера и структура
  папок сохранилась.
- **Неверный пароль** приводит к внятной ошибке, а не к тихому мусору.
- **Поиск первого тома** для всех раскладок: `.part1.rar`, `.part01.rar`,
  `.rar` + `.r00`, `.rar.001`.
- **Разбор ссылки** во всех видах, со слэшем и параметрами на конце.

## Чего тесты не покрывают

Обращения к самому Mail.ru — в песочнице, где писался код,
`cloud.mail.ru` закрыт сетевой политикой. Разбор ответов их API
(`/api/v2/folder` и `/api/v2/dispatcher`) написан по документированной
схеме, но вживую не прогонялся. Если Mail.ru поменял формат ответа —
сломается шаг 4, и ошибка покажет кусок ответа, по которому это чинится.

## Ограничения

- Colab даёт около 100 ГБ диска. Пик — примерно два размера архива
  (сам архив плюс распакованное), так что потолок где-то 45–50 ГБ на курс.
  Архивы удаляются сразу после распаковки.
- Плеер Google Drive играет `mp4`, но не `mkv`.
- Скорость упирается в отдачу Mail.ru, а не в канал Colab.
